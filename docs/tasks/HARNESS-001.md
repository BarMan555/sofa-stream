# HARNESS-001: практический harness разработки

Статус: done. Локальная проверка: 12 октября 2026 года, macOS arm64, .NET SDK 10.0.102.

## Результат для пользователя

Разработчик или агент получает карту проекта, критерии задачи, воспроизводимое локальное окружение и команды проверки с сохраняемой диагностикой. Работа начинается из Git-корня с `SofaStream.sln`.

## Критерии приёмки и результаты

- Чистая копия исходников без `.env`, `node_modules`, `bin` и `obj` устанавливает npm-зависимости, собирает API, применяет миграции и запускает фронтенд. Проверено на временной копии; установка использовала локальный npm-кеш.
- `check` и `check:full` проверяют приложение едиными командами. Полный набор прошёл: 6 существующих .NET-тестов, 4 клиентских, 3 проверки harness, 6 интеграционных и 3 браузерных сценария. Сборка без предупреждений и ошибок.
- Интеграционные проверки используют настоящий PostgreSQL и два SignalR-клиента. Браузерные сценарии проверяют вход двух участников, управление воспроизведением и смену ведущего с настоящими HTTP, SignalR и БД.
- Ошибки дают ненулевой код и сохраняют сводку, логи и браузерную диагностику. Самопроверка harness подтверждает сохранение кода ошибки и маскирование тестовых секретов. Неуспешные браузерные запуски также сохранили консоль и traces обоих клиентов.
- Временный браузерный контейнер и том удаляются после успеха и ошибки. Остановка dev освобождает порты, выключает контейнеры и сохраняет его базу. Это проверено отдельно; временная dev-база проверки затем удалена.
- `doctor` и `diagnose` прошли. Docker-образ API собран на Linux arm64 с закреплённым SDK и locked restore. Из контекста исключены зависимости, отчёты, локальное окружение и каталоги сборки, включая старые имена с обратной косой чертой.

## Ограничения

GitHub Actions настроен на те же проверки; удалённый запуск CI ещё не выполнялся. Настройки защиты ветки не менялись.

В браузерах используется управляемый плеер. Настоящие YouTube/RuTube, слышимость видеочата и соединение между разными сетями требуют отдельных сценариев из [runbook](../harness.md).

Открытые дефекты приложения остаются в [backlog](../backlog.json). Браузерные проверки сворачивают видеочат штатной кнопкой из-за перекрытия управления (SS-008).

Автономный диспетчер, независимое агентное ревью и фоновая очередь относятся к HARNESS-002. Для текущего этапа подготовлены команды, сводки, инструкции, навыки и задачи.
