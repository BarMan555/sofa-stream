# SS-008: видеочат не перекрывает управление комнатой

Статус: done. Ветка серии: `fix/backlog-priority-five`.

## Критерии приёмки

- При открытом видеочате кнопка выхода, загрузка видео и Play/Pause/перемотка доступны обычным кликом.
- Обычное окно и узкий экран не имеют наложений чата на управление и горизонтальной прокрутки.
- Сворачивание/восстановление и переход в fullscreen сохраняют доступ к управлению.
- Общий браузерный вход и выход работают без обязательного предварительного сворачивания чата.

## Проверка

Регрессионные браузерные сценарии до исправления; Playwright hit testing обычным кликом, узкое окно, fullscreen/возврат, снимки для визуальной проверки; полный harness после изменения пути размещения чата.

Задача выбрана пятой в серии после подтверждённой недоступности скачивания исправленного SDK для SS-009. Предыдущие изменения сохраняются.
