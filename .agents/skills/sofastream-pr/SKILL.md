# PR и выпуск SofaStream

- По просьбе пользователя опубликуй ветку задачи и открой PR в `main`. Используй [формат коммита](../sofastream-commit/SKILL.md) для заголовка PR и итогового коммита. В описании укажи результат и выполненные проверки.
- По просьбе влить PR проверь diff и убедись, что CI прошёл для текущего SHA. При необходимости дождись ручной приёмки. Используй **Squash and merge** с проверенным SHA.
- После merge обнови сведения об `origin/main` и тегах. Опубликуй аннотированный тег на итоговом squash-коммите, начиная с `v0.1.0` и повышая patch на один за каждое следующее вливание. При повторной попытке используй тег того же squash-коммита, сохраняя опубликованные теги.
- Сверь SHA опубликованного тега с результатом PR и проверь его наличие в истории `origin/main`. Удали завершённую ветку локально и на GitHub, если её вершина не менялась после проверки. Согласие на merge включает тег и очистку.
