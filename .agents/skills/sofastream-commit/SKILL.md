# Коммит SofaStream

1. Уточни по diff, какие правки относятся к задаче. Выполняй коммит в её ветке по просьбе пользователя.
2. Возьми фактический ID из [бэклога](../../../docs/backlog.json). Если у новой задачи ещё нет ID, присвой свободный номер и внеси её в бэклог.
3. Начни сообщение с ID. Пример — `[SS-006]: Приглушать видео во время разговора`. Обычно достаточно одной строки. Добавь абзац, если существенное решение требует пояснения.
