# Работа над SofaStream

Открывай в Codex папку с `SofaStream.sln`. Задачу можно написать прямо в чате или выбрать из [бэклога](docs/backlog.json). Для начала достаточно описать, что пользователь должен увидеть.

Веди задачу в рабочей ветке одним агентом. Учти текущие правки, внеси изменение и проверь результат. Для бага выбери проверку, на которой видно исходную ошибку. В ответе кратко напиши, что изменилось, что проверил и что ещё требует ручной проверки.

- Для локального запуска — `npm run dev`. Для быстрой проверки кода — `npm run check`.
- Если изменение затрагивает взаимодействие браузера, API, SignalR или базы, используй `npm run check:full`. Для правок текста проверь ссылки и команды. Настройка окружения и сценарии с настоящими плеерами описаны в [справочнике проверок](docs/harness.md).
- По устройству приложения смотри [карту кода](docs/architecture.md), по интерфейсу — [дизайн](docs/design.md).
- Коммит, публикация и вливание выполняются по просьбе пользователя. Перед соответствующим действием сверься с [правилами Git](docs/workflow.md).
